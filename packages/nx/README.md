# @cdk-x/nx

Nx plugin for scaffolding and building jsii-enabled TypeScript libraries in the cdk-x family.

See [PLUGIN.md](./PLUGIN.md) for the generator, inferred targets, and executor reference.

## Building

Run `nx build nx` to build the plugin.

## Running unit tests

Run `nx test nx` to execute the unit tests via [Jest](https://jestjs.io).
